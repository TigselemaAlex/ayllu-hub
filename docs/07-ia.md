# 07 — Trabajo con IA

*Estado: aprobado.*

**Convención de idioma:** todo el código en inglés; la documentación en español. El glosario de abajo traduce cada término del dominio para que código y documentos digan lo mismo.

## Glosario del dominio

| Documentos | Código |
| --- | --- |
| Condominio | `Condominium` |
| Unidad | `Unit` |
| Persona | `Person` |
| Vínculo (propietario / inquilino) | `UnitMembership` (`OWNER` / `TENANT`) |
| Cargo (tesorera, presidente, vicepresidente, secretario, guardia) | `Position` (`TREASURER`, `PRESIDENT`, `VICE_PRESIDENT`, `SECRETARY`, `GUARD`) |
| Parqueadero azul | `ParkingSpot` |
| Arriendo de parqueadero | `ParkingLease` |
| Cobro | `Charge` |
| Alícuota | `Dues` (tipo de cobro `DUES`) |
| Cuota extraordinaria | `SpecialAssessment` |
| Tipo de multa / Multa | `FineType` / `Fine` |
| Pago | `Payment` |
| Comprobante | `PaymentProof` |
| Aplicación (reparto del pago) | `PaymentAllocation` |
| Recibo | `Receipt` |
| Condonación | `ChargeWaiver` |
| Notificación | `Notification` |
| Reglamento | `Bylaws` |
| Mora | `overdue` |

## Uso recomendado

- Las reglas para Claude están en el `CLAUDE.md` de la raíz del repositorio.
- En las piezas que haces por primera vez, activa además el estilo de salida Learning de Claude Code. Cuando ya domines algo, puedes volver al estilo normal para avanzar más rápido.
